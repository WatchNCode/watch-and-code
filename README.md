# Watch & Code

مشاريع حقيقية بـ JavaScript و React والذكاء الاصطناعي، **بالعربي**.
كود كل فيديو من قناة [Watch & Code على يوتيوب](https://www.youtube.com/@WatchNdCode) في فولدر لوحده.

## المشاريع

| # | المشروع | اللي هتتعلمه | الكود |
|---|---|---|---|
| 01 | تطبيق طقس | fetch · async/await · API · try/catch · localStorage | [01-weather-app](01-weather-app) |
| 02 | لعبة X-O ضد الكمبيوتر | arrays · منطق الفوز · مخ للكمبيوتر · JSON · setTimeout | [02-xo-game](02-xo-game) |
| 03 | 10 أخطاء JavaScript | أنواع البيانات · == و === · defer · map · await · let · spread · sort · floating point | [03-js-mistakes](03-js-mistakes) |

## تشغّل أي مشروع إزاي
1. نزّل الكود: زرار **Code** ⬅ **Download ZIP**.
2. افتح فولدر المشروع في VS Code.
3. شغّل `index.html` بإضافة **Live Server**.

لو المشروع فادك، اعمله ⭐ وشاركه مع صاحبك اللي بيتعلم برمجة.
