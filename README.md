## تشغّل أي مشروع إزاي
1. نزّل الكود: زرار **Code** ⬅ **Download ZIP**.
2. افتح فولدر المشروع في VS Code.
3. شغّل `index.html` بإضافة **Live Server**.

لو المشروع فادك، اعمله ⭐ وشاركه مع صاحبك اللي بيتعلم برمجة.
