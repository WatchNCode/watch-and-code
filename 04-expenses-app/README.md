# 04: تطبيق مصروفات

![شكل التطبيق](preview.png)

تطبيق تسجّل فيه مصروفاتك، ويجمعها، ويرسمها في رسم بياني بالتصنيف. وكل حاجة بتفضل محفوظة حتى لو قفلت الصفحة.
JavaScript بس، والرسم البياني شوية `div` من غير أي مكتبة.

📺 **الشرح:** [الفيديو على يوتيوب](https://www.youtube.com/@WatchNdCode)

## اللي هتتعلمه
- `select` و `option`: قايمة تختار منها التصنيف.
- `localStorage` مع `JSON.stringify` و `JSON.parse`: الحفظ.
- `reduce`: نجمع كل المبالغ في رقم واحد.
- `Number()`: علشان `"150" + 80` ماتطلعش `"15080"`.
- `filter`: نمسح مصروف.
- `for...of` و `for...in`: نلف على array وعلى object.
- `textContent` بدل `innerHTML` للنص اللي المستخدم كتبه.
- رسم بياني بالنسبة المئوية و `Math.round`.

## 💪 التحدي
خلّي التطبيق يعرض مصروفات الشهر ده بس. محتاج تحفظ التاريخ مع كل مصروف.
حط الحل بتاعك في كومنتات الفيديو.
